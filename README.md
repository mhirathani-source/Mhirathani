# Prime Boxing Academy Management System

نظام ويب عربي لإدارة أكاديمية ملاكمة واحدة. الواجهة باتجاه RTL، والتاريخ المحلي `Asia/Amman`، وتُحفظ المبالغ بالدينار الأردني على هيئة فلس صحيح لتجنّب أخطاء الكسور.

## الحالة الحالية

المرحلة الأولى: تأسيس التطبيق، تسجيل الدخول، صلاحية المدير الأول، قاعدة بيانات PostgreSQL، وسجل تدقيق أساسي. توجد وظائف فعلية للمشتركين والباقات والاشتراكات والدفعات والإيصالات. المصاريف والرواتب والتقارير وواتساب ما تزال قيد التطوير ولا تعرض بيانات افتراضية.

## التشغيل

- شغّل واجهة الويب من سير العمل `artifacts/club-manager: web`.
- شغّل الـAPI من سير العمل `artifacts/api-server: API Server`.
- للتحقق من الأنواع: `pnpm run typecheck`
- لمزامنة مخطط قاعدة بيانات التطوير: `pnpm --filter @workspace/db run push`

تُدار قاعدة PostgreSQL من Replit. لا تُدرج بيانات مشتركين تجريبية أو مفاتيح في ملفات المشروع. تغييرات مخطط قاعدة بيانات الإنتاج يجب أن تمر عبر مسار النشر المدعوم، ولا يُنشر التطبيق قبل ضبط المدير الأول والتحقق من تسجيل الدخول.

## إعداد المدير الأول

1. أنشئ حسابًا من صفحة التسجيل في بيئة التطوير باستخدام البريد الإلكتروني الذي سيُخصّص للمدير.
2. اضبط المتغير غير السري `CLUB_ADMIN_EMAIL` على البريد نفسه من أدوات متغيرات البيئة.
3. سجّل الدخول مجددًا. يُنشأ سجل المدير تلقائيًا فقط للحساب المطابق؛ أما أي حساب آخر فلا يحصل على وصول للنادي.

إعدادات Clerk السرية مُدارة في Replit Secrets. لا تُنشئ كلمة مرور ثابتة أو تشاركها.
