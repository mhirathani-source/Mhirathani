المستخدم وافق على «إتاحة التحميل للعامة مع بقاء تسجيل دخول النادي محميًا».

**Why:** يحتاج رابط تثبيت PWA عامًا للهواتف دون فتح بيانات النادي أو منح صلاحيات إدارة للزائر.

**How to apply:** صفحة التثبيت خارج تسجيل دخول التطبيق، لكن لا تُزل مصادقة النادي أو فحوص صلاحيات الخادم عند تغيير إتاحة النشر. تغيير حماية النشر لا يعني جعل سجلات النادي عامة.
