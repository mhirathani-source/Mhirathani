# Prime Boxing Academy Manager v2

هذه نسخة عرض مستقلة للمدير والاستقبال، وليست بديلًا للنظام الحقيقي الموجود في `artifacts/club-manager`.

## التشغيل

- افتح معاينة **Prime Boxing Academy Manager v2** أو المسار `/prime-v2/`.
- استخدم أحد حسابَي العرض المبيّنين في صفحة الدخول. لا يوجد تسجيل ذاتي أو حساب دخول للطلاب.
- البيانات وهمية وتُحفظ في ذاكرة الصفحة فقط. تحديث الصفحة يعيد البيانات الأصلية ويُنهي جلسة الدخول.
- تغيير الحساب داخل الصفحة دون تحديثها يسمح بتجربة أدوار الموظفين على بيانات العرض المحلية نفسها.

## حدود النسخة

- واجهة عربية RTL داكنة، خلفية `#0F0F0F`، لون ذهبي `#FFC107`، وخط Tajawal.
- الموظف يدير بيانات المشتركين والاشتراكات والتذكيرات والحضور. أسعار الباقات ظاهرة له لإضافة الاشتراكات، لكن الإجماليات المالية وإدارة الموظفين للمدير فقط.
- جميع المبالغ والحركات المالية تجريبية. تسجيل الإيراد هنا لا يسجل دفعة في قاعدة بيانات النادي الحقيقية.
- تفعيل واتساب وإرسال التذكير **محاكاة فقط**؛ لا يربطان حساب Meta ولا يرسلان رسالة إلى رقم هاتف.
- حسابات الدخول وصلاحياتها محلية وقابلة لفحصها في شيفرة المتصفح. لا تستخدم هذه النسخة لحماية بيانات حقيقية، ولا تستعمل فيها كلمة مرور تستخدمها في أي حساب فعلي.
- لا توجد طلبات إلى API النظام الأصلي، ولا تغيير لبياناته أو صلاحياته أو إعدادات دخوله.

## النشر والنطاق

النطاق المطلوب هو `prime-boxing-academy.replit.app`، لكنه ليس رابطًا مُعتمدًا أو نشطًا بمجرد كتابة اسمه. يُختار اسم النطاق المتاح في شاشة النشر.

هذه النسخة مسجلة على `/prime-v2/` حتى يبقى النظام الأصلي على مساره الحالي. نشر المشروع الواحد ينشر تطبيقاته معًا على النطاق نفسه. إذا كان المطلوب أن تعمل v2 على جذر نطاق مستقل وبنشر منفصل، انقل النسخة إلى مشروع مستقل بدل تغيير مسار النظام الأصلي أو استبداله.

## فحوص التطوير

```bash
pnpm --filter @workspace/prime-manager-v2 run typecheck
pnpm --filter @workspace/scripts exec tsx --test ../artifacts/prime-manager-v2/src/lib/domain.test.ts
```

تغطي الاختبارات حسابات الدينار والفلس، ومواعيد الاشتراكات، والتحقق من الهواتف والتكرار، ومواعيد التذكيرات، واتساق البيانات التجريبية. اختبار المتصفح يستخدم حسابات العرض ولا يتصل بقاعدة بيانات النادي.
